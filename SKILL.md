# REDISEÑO COMPLETO DEL FRONTEND CON UNSLOP

Actúa como un **Senior Product Designer, UI/UX Engineer y Frontend Architect**, especializado en interfaces premium, productos SaaS y experiencias digitales de nivel comercial.

Quiero que ejecutes **Unslop** sobre todo el frontend de este proyecto para transformar completamente su diseño visual.

El objetivo es conseguir una interfaz profesional, moderna, coherente y con personalidad propia, eliminando cualquier apariencia de diseño genérico generado por IA.

# FASE 1. INSTALACIÓN Y CONFIGURACIÓN DE UNSLOP (OBLIGATORIA)

Antes de modificar el proyecto, debes instalar y configurar el repositorio oficial:

**Repositorio:** https://github.com/OPSHARP/unslop.git

Debes seguir estos pasos:

1. Clona el repositorio oficial de OPSHARP.
2. Inspecciona su README, documentación, estructura y archivos de configuración.
3. Identifica el procedimiento oficial de instalación para Cursor.
4. Instala y configura Unslop siguiendo sus instrucciones oficiales.
5. Configura correctamente sus skills, reglas y archivos de referencia para que estén disponibles en el entorno de desarrollo.
6. Comprueba que Unslop está instalado y que puedes utilizar sus directrices.

**Importante:**
- No inventes comandos ni procedimientos de instalación.
- No simules que Unslop está instalado.
- No te limites a descargar o leer el repositorio.
- No continúes como si estuviera instalado si la configuración ha fallado.
- Si Antigravity no permite instalarlo directamente para Cursor, identifica la alternativa compatible y explica qué parte no puede configurarse.

Una vez completada la instalación, utiliza las directrices reales de Unslop durante todo el rediseño.

# FASE 2. AUDITORÍA COMPLETA DEL FRONTEND

Antes de tocar el código, analiza el proyecto en profundidad.

Inspecciona:
- Estructura completa del frontend.
- Todas las páginas y rutas.
- Componentes reutilizables.
- Layouts y navegación.
- Hojas de estilos y configuración de Tailwind, si existe.
- Variables CSS y sistema de diseño.
- Tipografías, colores y espaciados.
- Responsive actual.
- Estados de los componentes e interacciones.

Identifica los problemas de diseño, inconsistencias visuales y patrones típicos de interfaces generadas automáticamente.

No rediseñes basándote únicamente en la página principal. Necesitas comprender el producto en su conjunto.

# FASE 3. DIRECCIÓN ARTÍSTICA Y SISTEMA DE DISEÑO

Define una dirección visual propia que tenga sentido para el tipo de producto y sus usuarios.

Establece un sistema de diseño coherente:

- Paleta cromática con colores principales, secundarios y neutros.
- Tipografía y jerarquías tipográficas.
- Escala de espaciados.
- Sistema de grids y proporciones.
- Bordes, radios y separadores.
- Elevaciones y sombras.
- Estilos de botones, inputs y formularios.
- Iconografía.
- Estados interactivos.
- Animaciones y transiciones.

Evita aplicar una plantilla predeterminada. El diseño debe tener una identidad reconocible y estar pensado específicamente para este proyecto.

# FASE 4. REDISEÑO E IMPLEMENTACIÓN

Rediseña todas las páginas y componentes del frontend.

Presta especial atención a:

**Composición y estructura**
- Distribución de los elementos.
- Jerarquía visual.
- Aprovechamiento del espacio.
- Alineación y proporciones.
- Equilibrio entre contenido y elementos visuales.

**Componentes**
- Navegación y menús.
- Botones y acciones.
- Formularios e inputs.
- Tablas y listados.
- Tarjetas y paneles.
- Modales y desplegables.
- Notificaciones.
- Estados vacíos y mensajes de error.

**Experiencia visual**
- Tipografías bien seleccionadas.
- Iconos profesionales y consistentes.
- Microinteracciones.
- Animaciones sutiles.
- Hover, focus y active states.
- Transiciones fluidas.
- Feedback visual de las acciones.

No te limites a cambiar colores, fuentes y border-radius. Quiero una mejora real de la composición y del lenguaje visual.

# FASE 5. ELIMINAR EL ASPECTO DE DISEÑO GENERADO POR IA

Aplica rigurosamente estos criterios:

- Evita gradientes morados y azules sin justificación.
- Evita glassmorphism innecesario.
- No abuses de sombras, brillos o efectos decorativos.
- No conviertas absolutamente todo en tarjetas.
- Evita bordes redondeados exagerados.
- No utilices emojis como iconos.
- Evita layouts repetitivos y secciones clónicas.
- No abuses de los contenedores con fondos diferentes.
- No añadas elementos decorativos sin propósito.
- Evita interfaces sobrecargadas.

Prioriza:
- Personalidad visual.
- Claridad y legibilidad.
- Espacio en blanco.
- Jerarquía bien definida.
- Contraste equilibrado.
- Composiciones interesantes.
- Consistencia.
- Atención al detalle.

Cada elemento debe tener una razón de existir.

# FASE 6. RESPONSIVE Y ACCESIBILIDAD

Asegúrate de que todo el rediseño funcione correctamente en:

- Escritorio.
- Portátiles.
- Tablets.
- Móviles.

Comprueba:
- Menús adaptativos.
- Distribución de grids.
- Tamaños de texto.
- Espaciados.
- Tablas y elementos desbordados.
- Botones táctiles.
- Formularios.
- Navegación móvil.

Mantén buenas prácticas de accesibilidad, contraste y navegación mediante teclado.

# FASE 7. RESTRICCIONES TÉCNICAS

Es imprescindible respetar el funcionamiento actual del proyecto.

- No elimines funcionalidades existentes.
- No modifiques la lógica de negocio.
- No alteres APIs ni endpoints.
- No modifiques la base de datos.
- No cambies la autenticación.
- No rompas rutas ni navegación.
- Respeta el stack tecnológico.
- No sustituyas tecnologías sin justificación.
- Reutiliza componentes cuando tenga sentido.
- Evita dependencias innecesarias.

Puedes refactorizar componentes y estilos si mejora la arquitectura visual, siempre que mantengas su comportamiento.

# FASE 8. VALIDACIÓN FINAL

No des por terminado el trabajo cuando simplemente hayas modificado los archivos.

Debes:

1. Ejecutar el proyecto.
2. Comprobar que compila correctamente.
3. Revisar visualmente las páginas.
4. Comprobar las interacciones.
5. Verificar el responsive.
6. Corregir errores visuales.
7. Comprobar que las funcionalidades siguen funcionando.
8. Eliminar estilos obsoletos o duplicados cuando sea seguro.

Si tienes acceso a herramientas de navegador, utiliza capturas de pantalla para comparar el resultado antes y después.

Quiero una transformación visual completa, no un simple lavado de cara.

Trabaja como si estuvieras preparando este producto para un lanzamiento comercial real.
